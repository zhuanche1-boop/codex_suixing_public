# Codex 随行 1.4.0

历史版本补录，归档日期：2026-11-10。保留原 APK 内部版本 1.4.0 / code 7；文件统一使用 Codex-Suixing 名称。

## 本版变化

- 改为更紧凑的聊天布局，减少头部占用。
- 新增电脑本地图片预览和主动保存，图片以有限内存缓存展示。
- 新增独立 ChatGPT 标签页，可查看、继续及重命名已有普通聊天。
- 修复保存图片时页面重建导致目标丢失，以及自动刷新使长回复阅读位置跳回的问题。

## 归档与兼容说明

- ChatGPT 能力不等同于本地 Codex 项目；不支持普通新建、模型设置或云端附件预览。
- Windows 按本版已留存电脑模块重新封装为字节码，使用固定 Node 22.23.4 x64；初始化工具采用当前发行方案。
- 完成历史 Node 行为测试与字节码回归，不等同于重新通过所有当前桌面版本及手机真机验证。
- 历史版本供回溯；日常使用优先选择最新版本。Android 降级可能被系统拒绝，不要为试旧版卸载主力 App 丢失配对和草稿。
- 安装方法见本版附带的使用说明；源码只保存在私有仓库。
