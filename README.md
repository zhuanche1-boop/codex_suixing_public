# Codex 随行 1.4.7

历史版本补录，归档日期：2026-11-10。保留原 APK 内部版本 1.4.7 / code 14；文件统一使用 Codex-Suixing 名称。

## 本版变化

- 将额度入口改为剩余比例圆环，灰色表示尚未获取额度，点击查看详情并手动刷新。
- 扩大额度入口点击区域，不新增后台定时查询。

## 归档与兼容说明

- 原开发记录明确该手机版本沿用 1.4.6 电脑程序，因此本次以对应 1.4.6 原始电脑模块打包。
- 缺少完整 1.4.7 Android 源码快照：仅保留原 APK、可验证的电脑模块和版本来源记录，不把 1.4.6 手机源码标成 1.4.7。
- Windows 按本版已留存电脑模块重新封装为字节码，使用固定 Node 22.23.4 x64；初始化工具采用当前发行方案。
- 完成历史 Node 行为测试与字节码回归，不等同于重新通过所有当前桌面版本及手机真机验证。
- 历史版本供回溯；日常使用优先选择最新版本。Android 降级可能被系统拒绝，不要为试旧版卸载主力 App 丢失配对和草稿。
- 安装方法见本版附带的使用说明；源码只保存在私有仓库。
