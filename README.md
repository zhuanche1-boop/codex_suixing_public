# Codex 随行 1.3.1

历史版本补录，归档日期：2026-11-10。保留原 APK 内部版本 1.3.1 / code 6；文件统一使用 Codex-Suixing 名称。

## 本版变化

- 相对最近留有完整源码的 1.2.0，项目与文件操作扩展为：上传手机文件、浏览电脑文件与目录、引用文件或文件夹。
- 新增已有项目中新建会话、重命名会话，以及项目置顶、分区、打开目录与归档空闲聊天。
- 新增模型和思考强度选择，随下一条指令提交；手机历史限制为最近 60 条，超长读取可降级处理。
- 完善后台长轮询、极短任务完成检测，以及连接切换和未知发送结果保护。

## 归档与兼容说明

- 1.3.0 对应源码缺失，无法严格划分 1.3.0 与 1.3.1 的全部增量；上述变化以最后完整快照 1.2.0 为比较基线。
- Windows 按本版已留存电脑模块重新封装为字节码，使用固定 Node 22.23.4 x64；初始化工具采用当前发行方案。
- 完成历史 Node 行为测试与字节码回归，不等同于重新通过所有当前桌面版本及手机真机验证。
- 历史版本供回溯；日常使用优先选择最新版本。Android 降级可能被系统拒绝，不要为试旧版卸载主力 App 丢失配对和草稿。
- 安装方法见本版附带的使用说明；源码只保存在私有仓库。
